# Jornada Fundamentos em Python 🐍

Este repositório foi criado para documentar a minha base prática em programação, construída de forma 100% consistente ao longo de mais de 60 dias de foco diário antes do início da minha graduação em Sistemas de Informação. 

Aqui estão reunidos mais de 130 exercícios estruturados, divididos entre lógica essencial, tratamento de dados e Programação Orientada a Objetos (POO).

---

## 🛠️ Tecnologias e Conceitos Explorados

*   **Lógica de Programação:** Estruturas condicionais (`if/elif/else`), laços de repetição (`while/for`) e controle de fluxo.
*   **Estruturas de Dados:** Manipulação de Listas, Tuplas e Dicionários.
*   **Modularização:** Criação de funções e utilização de pacotes/módulos externos.
*   **Programação Orientada a Objetos (POO):** Criação de classes, métodos, encapsulamento e os pilares fundamentais de POO aplicados a desafios práticos.

---

## 📂 Estrutura do Repositório

*   `/` (Raiz): Contém os 117 exercícios sequenciais focados em lógica de programação e algoritmos básicos.
*   `/desafios-poo`: Pasta dedicada aos 13 desafios práticos estruturados sob o paradigma de Programação Orientada a Objetos.
